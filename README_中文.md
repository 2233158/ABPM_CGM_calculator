# ABPM 一体化双语分析系统（EN / 中文）

一个用于分析 24 小时动态血压（ABPM）数据的一体化 R Shiny 应用。可直接读入
Mobil-O-Graph 24h PWA 原始设备导出文件或整理好的 CSV，输出完整指标集——
日间、夜间与 24 小时的统计量（均值、SD、CV、ARV、VIM、AUC、TTR 等），
并对照 ESC 2024、AHA/ACC 2025 与中国 2024 指南目标进行判定；另含可选血糖
（CGM）域，按 ADA 2025 与《中国糖尿病防治指南 2024》目标评估。界面中英双语
可随时切换，结果可导出 CSV 或 Excel 供后续研究分析。

- 主程序：`ABPM_calculator_integrated.R`（单文件）
- 详细手册：`使用说明_中文.md`（中文）· `README_English.md`（英文）
- 部署指南：`部署到shinyapps.io指南.md`

## 1. 运行环境

- R（建议 4.0 及以上）+ RStudio。
- 首次运行需联网，程序会自动安装缺失的依赖包
  （`shiny, dplyr, stringr, DT, shinythemes, shinyjs, tidyr, zoo, plotly,
  ggplot2, openxlsx, readxl, rintrojs, zip`）。

## 2. 启动应用

RStudio：打开 `ABPM_calculator_integrated.R`，点击 **Run App**。

终端：

```r
shiny::runApp("ABPM_calculator_integrated.R")
```

应用默认英文界面启动，顶部 **EN / 中文** 开关可随时切换；切换后已导入的数据、
设置与计算结果全部保留。

**没有数据也能试。** 两条输入路径各配了内置演示：

- *预处理 CSV 路径*：勾选【使用内置示例数据 (P001-P010)】。
- *原始设备导出路径*（默认勾选）：【使用内置设备样本 (50002/50003)】——
  两份匿名化真实 24h PWA 导出，走与上传原始文件完全相同的
  转换 → 预览 → 载入流程。

## 3. 六步使用流程

1. **导入数据**——两条输入路径：
   - *预处理 CSV*：把列映射到 `MASKID / Time / SBP / DBP / HR / PP / MAP`
     （系统自动识别别名并预选），点击【应用映射】；
   - *原始设备导出*：核对每个文件的 MASKID，点击【转换】，再【载入分析】；
     也可【下载预处理后 CSV】。
2. **定义日夜时间与分析选项**——设置 Day1/Day2 的白天与夜晚开始时间
   （预设：东亚 05-20、欧美 07-22）、插补模式与 VIM 模式。
3. **处理数据**——点击【1. 处理数据】。
4. **设置目标范围**——日间/夜间/24h 的 SBP/DBP/HR 上下限；PP/MAP 可选，
   可由 SBP/DBP 自动推导。
5. **计算指标**——点击【2. 计算指标】，生成四套结果：日间、夜间、
   24h（日夜统一阈值）、24h（日夜分段阈值）。
6. **查看与导出**——可视化、个性化分析（按各时段对照 ESC 2024 /
   AHA/ACC 2025 / 中国 2024 指南判定高血压 + 四维度评估），
   然后勾选导出内容并下载 **CSV（zip）**或 **Excel**。

顶部栏的**引导按钮**可在应用内交互式走一遍上述步骤；【使用说明】页签提供
同样的逐步手册与常见问题（FAQ）。

## 4. 可选血糖（CGM）域

侧栏的**数据域**开关在 ABPM 之外增加血糖域：支持原始 CGM 导出或处理好的
血糖 CSV，内置一份 **14 天匿名化 CGM 记录**作为示例。血糖结果以 `GLU_*`
前缀区分，按四维度（均值、CV、TIR、TAR/TBR 负荷）对照 ADA 2025 与
中国糖尿病指南 2024 目标评估。

## 5. 输入格式速览

- **预处理后 CSV**：首行为列名；仅 `MASKID` 与 `Time` 必填，
  `SBP/DBP/HR/PP/MAP` 各列全部可选（血糖 `GLU` 列同样可选）；Time 格式
  `HHMM+XD`（如 `0807+0D`）或 `HHMM`。多个文件允许列结构不同，按列名合并。
- **原始 Mobil-O-Graph 24h PWA 导出**（`.xls` / `.xlsx`）：单 sheet，上方为
  元数据行。转换保留设备实测 `pPP`/`MAP`，剔除 0 值的失败读数并报告剔除
  条数；患者编号自动读取文件内元数据的 ID。

## 7. 注意事项

- 输出用于研究分析，不能替代临床诊断与医生面诊。
- 本地源码默认启用文件上传（`DEMO_MODE_DEFAULT <- FALSE`）；演示版隐藏上传，
  仅保留内置演示路径。
- 完整说明（数据格式、计算契约、部署细节）见 `使用说明_中文.md`。
